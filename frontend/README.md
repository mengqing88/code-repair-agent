# 代码修复工作台 · v0

Vue 3 + TypeScript + Vite 前端，采用已确认的暖黑、灰绿、薄荷绿视觉系统。

## 当前范围

- 任务输入：代码文件（扩展名不限）、固定版本 Git 仓库或直接粘贴 Python 代码。
- 必填错误报告、可展开的 pytest 验收目标、四项默认预算。
- 校验任务输入并展示摘要；文件选择器读取用户主动选择的文本文件。
- 明确标注的补丁审核示例，包括差异、根因、验证结果占位、接受、拒绝理由与本页审核记录。
- 桌面三栏、窄屏单列布局，键盘焦点与减少动态效果支持。

当前阶段用于确认布局与交互。数据仅保存在页面内存中；刷新页面后清空。
尚未接入 Python/LangGraph、真实测试或数据库，不调用模型，不写入审核数据库。
手填文件路径只做输入收集；浏览器不能直接读取任意本地路径。
拒绝理由必填，接入真实接口后仍需由服务端校验并写入 `repair_reviews`。

## 本地运行

```powershell
cd F:\项目1\frontend
npm.cmd install
npm.cmd run dev
```

打开 `http://127.0.0.1:5173`。

```powershell

```

## 代码结构

- `src/App.vue`：工作区布局、页面切换和本页预览状态。
- `src/components/TaskComposer.vue`：代码/报告输入、文件读取和前端校验。
- `src/components/ReviewPanel.vue`：补丁审核示例和拒绝理由输入。
- `src/components/AppIcon.vue`：导航与操作图标。
- `src/types.ts`：表单、审核记录类型，以及与 Python 默认值一致的预算展示。
- `src/style.css`：视觉变量、组件样式、响应式布局。
